## 4. Système bilingue (i18n)

Deux mécanismes, qui réagissent tous deux à l'événement **`langChanged`** émis par `GlobalLang.set()` :

1. **Dictionnaire + `data-i18n`** (pages outils) : le script de page déclare `const i18n = { FR:{…}, EN:{…} }` ; le HTML porte `data-i18n="clé"` (ou `data-i18n-placeholder`) ; `GlobalLang.applyI18n(i18n[lang])` remplace le texte.
2. **`data-en` / `data-fr` sur l'élément** (pages de texte, base de données) : un script applique l'attribut de la langue courante.

**Le HTML servi est en anglais**, `<html lang="en">`, et le français est appliqué par le JS. Google indexe le rendu anglais ; un visiteur réglé en français voit l'anglais un instant avant la bascule. Toute nouvelle page s'écrit donc en anglais en dur, la traduction dans `data-fr` ou le dictionnaire.

**Exception : `fr/shop/theater-shop.html`, pilote « une URL par langue ».** Deux adresses, une par langue, reliées par `hreflang` (`en`, `fr`, `x-default` vers l'anglais), chacune avec sa canonique. La jumelle est du HTML français en dur (`<html lang="fr">`, `<base href="../../">`). Six lignes en ligne dans cette page, jamais dans `lang.js` : `GlobalLang.get()` y renvoie toujours `FR` (l'adresse décide, pas la préférence) ; `GlobalLang.set('EN')` emmène vers la page anglaise ; la préférence `FR` n'est écrite que si le visiteur n'en avait aucune. Un lien visible « Version française de cette page » (`.sx-langalt`, partial `theater-shop.lang-alt.html`) mène de l'anglaise à la française ; pas de lien inverse en dur, le bouton de langue de la page française fait ce trajet en enregistrant la préférence (un lien simple ouvrirait la page anglaise traduite en français). Portée : cette page seulement, chaque page dupliquée étant à maintenir en double.

**Préférence** : clé `hub_lang`, défaut `EN`. Bouton rond « globe + code » dans le header sur ordinateur (`hdrInitLangToggle`) ; sous 820 px et en header condensé, la langue passe dans le drawer ou le panneau profil.

**Où ajouter un texte** : page outil, la clé dans les deux blocs du dictionnaire du script + `data-i18n` ; page de texte, `data-en`/`data-fr` ; nom d'outil ou de catégorie, dans `site-config.js` (`name: {EN, FR}`), jamais en dur.
